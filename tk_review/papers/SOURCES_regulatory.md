## Notes on retrieval obstacles encountered

- **oehha.ca.gov HTML pages** are behind Imperva/Incapsula; `curl` of a landing page returns a 212-byte JavaScript challenge and WebFetch returns empty content. **Direct PDF paths under `/sites/default/files/media/...` and `/media/downloads/...` work normally.** PDF URLs had to be discovered through web search rather than by crawling the landing page.
- **www.atsdr.cdc.gov** rejects requests without a full browser header set (User-Agent + Accept + Accept-Language + Referer + Sec-Fetch-*). See row 7.
- **efsa.onlinelibrary.wiley.com** is Cloudflare-protected against both `curl` and WebFetch. See row 11.
- **pmc.ncbi.nlm.nih.gov/articles/*/pdf/** serves a download interstitial rather than the PDF. See row 12.
- `pdftotext` (poppler) was available; `pypdf` was not installed and was not needed.
